# Python Practice Workspace

A personal collection of Python exercises, worksheets, assignments, contest
solutions, and practice code.

## Structure

- `assignments/` - course assignments and worksheet solutions
- `after_mid_terms/` and `before_midterms/` - exam practice
- `codeforces/` - Codeforces solutions
- `problem_solutions/` - standalone problem solutions
- `loops_and_series/` - loops and series exercises
- `day_05/`, `day_06/`, and `class_06/` - class exercises
- `worksheet_*/` - numbered worksheet exercises

Older folders and exercise names may remain where changing them could affect
imports or external links.

## Working with Python files

Use Python 3.14 or a compatible release:

```powershell
py main.py
```

Generated folders, caches, and editor files should not be committed.
